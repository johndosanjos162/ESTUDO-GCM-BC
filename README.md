# Estudos GMBC

Aplicativo web de estudos para concurso da Guarda Municipal de Balneário Camboriú.

## Tecnologias
- Streamlit (frontend)
- Supabase / PostgreSQL (backend)
- OpenAI (geração de questões)

## Disciplinas
- Língua Portuguesa
- Matemática
- Legislação da Guarda Municipal
- Conhecimentos de Balneário Camboriú

## Ciclo semanal
Alterna automaticamente entre Semana A e Semana B.
